# NutriTrack - Vanilla Calorie & Macro Tracker

A modern, fast, client-side Calorie & Macronutrient Tracker built using **Vanilla HTML5, CSS3, and JavaScript**.

Zero external dependencies, zero backend required, zero CSS variables, zero Tailwind. All data persists locally in the browser via `localStorage`.

---

## ✨ Features

- **Daily Calorie Dashboard**: Circular progress ring, real-time remaining calories, consumed count, and status indicators.
- **Macronutrient Tracking**: Interactive progress bars and calorie calculations for Protein (4 kcal/g), Carbohydrates (4 kcal/g), and Fats (9 kcal/g).
- **Dark (Black) & Light Mode Toggle**: One-click switcher between AMOLED pitch black and clean high-contrast light mode with preference persistence.
- **Categorized Daily Meal Log**: Log meals by Breakfast, Lunch, Dinner, and Snacks with subtotals, inline editing, and deletion.
- **Quick-Add Presets**: 1-click popular food presets to pre-fill the form instantly.
- **Goals & TDEE / BMR Calculator**: Built-in Mifflin-St Jeor formula calculating BMR, Maintenance TDEE, and recommended intake based on weight management goals, plus an auto-balanced macro split (30% P / 45% C / 25% F).
- **7-Day History & Analytics**: Responsive bar chart comparing daily intake to targets, weekly average, adherence rate, and jump-to-date functionality.
- **Data Portability**: Full JSON export and import for local backups, plus reset functionality.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No server setup or installation required!
